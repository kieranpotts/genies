= Front-ends

Ollama has a built-in chat interface that lets you interact with your local models from the CLI. Use `ollama run <model-name>` to launch it.

The built-in interface is minimal. Models do not have access to your filesystem or external systems, so this interface is not a full coding agent by itself.

To integrate your local models with other tools, use a front-end.

== VS Code extensions

If you use the GitHub Copilot Chat extension in VS Code, you can configure it to use Ollama as a provider. This sends API requests to your local Ollama server instead of GitHub's servers.

First, confirm Ollama is running locally and serving its HTTP API by opening http://localhost:11434/ in a browser. You should see "Ollama is running". If not, run `./run/ollama` from the repo directory or `ollama serve` if Ollama is installed locally.

Open the model picker in Copilot Chat. This is usually a dropdown at the bottom of the chat input box in the Copilot Chat panel. In the Language Models editor, check whether your locally-installed models have been discovered automatically. They may already appear under the "Ollama" provider.

If your local models are not listed, click the *Add Models* button and choose "Ollama". Enter `http://localhost:11434/`. VS Code will retrieve the available models from the Ollama API and let you select the ones you want.

Once configured, you can choose your local Ollama models from the Copilot Chat model picker.

''''

Even when using local Ollama models in Copilot Chat, you still need to be logged into GitHub. If you want a fully offline experience, use a different chat interface.

Alternative VS Code coding agents that can use Ollama as a back-end include:

* https://marketplace.visualstudio.com/items?itemName=Continue.continue[Continue]
* https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev[Cline]
* https://marketplace.visualstudio.com/items?itemName=rjmacarthy.twinny[Twinny]

Continue is an open source extension that connects directly to Ollama. It supports chat, inline autocompletion, and selecting code to ask questions about it.

Cline is more suited to multi-file and whole-repo changes, and can read, write, and navigate across files autonomously.

Twinny is a lightweight coding agent focused on autocomplete and is a good choice if you want fast local completions from Ollama models.

== Command line interfaces

If you prefer a terminal-based interface, https://aider.chat/[Aider] offers a similar experience to Claude Code or Copilot CLI. It supports Ollama as a back-end via Ollama's OpenAPI-compatible endpoint and works across a whole Git repository. Run it with:

[source]
----
aider --model ollama_chat/qwen2.5-coder:7b
----

See the website for further https://aider.chat/docs/llms/ollama.html[instructions for using Aider with Ollama].

https://github.com/TheR1D/shell_gpt[ShellGPT] (sgpt) is a general-purpose CLI tool for piping commands and text into a language model. Common uses include explaining errors and analyzing log files. Examples:

[source]
----
sgpt --model ollama/mistral "explain this error: segfault at 0x00"
cat error.log | sgpt "what's wrong here?"
----

https://github.com/danielmiessler/Fabric[Fabric] is a CLI tool built around reusable prompt templates for tasks such as summarizing output and writing commit messages. Like sgpt, it works well with piped input.

Finally, https://terminaltrove.com/oterm/[Oterm] is a terminal UI (TUI) that is more visually appealing than a raw CLI.
