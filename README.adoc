= Genies

This project is a self-hosted instance of Ollama, used for self-hosting open-source AI models like DeepSeek-V3/R1, Llama 3.3, and Qwen. Ollama provides a convenient platform for running these models locally, giving users control over their data and the ability to customize the models to their needs.
